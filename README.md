# 🚀 Portfolio

A modern, responsive Flutter portfolio application showcasing projects with intelligent categorization and easy-to-use contact options.

## ✨ Features

- **Project Portfolio** - Beautifully displayed projects with category filtering and badges
- **Smart Categorization** - Projects organized by type (Web, Mobile, UI/UX, etc.)
- **Contact Page** - Functional contact form with direct social media links
- **Responsive Design** - Works seamlessly across mobile, tablet, and desktop
- **Cross-Platform** - Built for Android, iOS, Web, macOS, Windows, and Linux

## 🛠️ Tech Stack

- **Framework**: Flutter
- **Language**: Dart
- **Styling**: Tailwind CSS concepts applied to Flutter
- **Architecture**: Modular structure with separate concerns

## 📂 Project Structure

```
lib/
├── main.dart              # Application entry point
├── theme_provider.dart    # Theme configuration
├── core/
│   └── style/            # Styling utilities
└── presentation/
    └── pages/            # UI pages (home, portfolio, contact, etc.)
```

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (latest version)
- Dart SDK

### Installation

1. Clone the repository
```bash
git clone https://github.com/Oliver9105/PORTFOLIO.git
cd PORTFOLIO
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the application
```bash
flutter run
```

### Available Platforms

Build and run on your target platform:

```bash
# Web
flutter run -d chrome

# Android
flutter run -d android

# iOS
flutter run -d ios

# Desktop (macOS, Windows, Linux)
flutter run -d macos
flutter run -d windows
flutter run -d linux
```
